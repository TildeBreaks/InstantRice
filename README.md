# High Fantasy Cyberpunk Hyprland Theme

This repository contains a complete Hyprland desktop configuration with a "High Fantasy meets Cyberpunk" theme. It is designed to be gaming-focused, tinker-friendly, and visually appealing.

## Features

*   **Dynamic Theming:** The color scheme of your desktop will automatically adapt to your wallpaper.
*   **Pre-configured Applications:** Comes with configurations for Hyprland, Kitty, Waybar, and Dunst.
*   **Easy Installation:** A simple setup script is provided to get you up and running quickly.

## Installation

1.  Clone this repository to your local machine.
2.  Run the `setup.sh` script from the root of the repository:
    ```bash
    ./setup.sh
    ```
3.  Restart Hyprland to apply the changes.

## Customization

To customize the theme, simply add your own wallpapers to the `hypr/wallpapers` directory. The `changetheme.sh` script will automatically detect them and include them in the random rotation.
